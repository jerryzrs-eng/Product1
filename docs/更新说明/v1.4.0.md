## 更新内容

- **每份课表可分别设置有效期。** 在“设置 → 课表与作息”中选择课表，可按周数或指定作废日期设置。默认有效 23 周，从开学所在周起算；未填写开学日期时，从首次启用日起算。指定作废日期从当天零点生效。
- **作废后自动隐藏课程。** 主界面的展开、折叠、下一天预览和快捷切换不再显示已作废课表的课程；课表仍保留在设置中，可查看并调整有效期。复制、导出导入和历史恢复保留有效期设置。
- **主界面滚动条更简洁。** 课程较多时显示纤细圆角滑块，悬停或拖动时加深并略微增宽，保留方便操作的透明区域。
- **完善跨日处理。** 休眠跨过作废日期后清理旧预览，跨零点的拖动也不会继续修改已作废课表。

## 安装与升级

下载 `KeBiao-Setup-1.4.0.exe`，适用于 64 位 Windows 10 / 11，已有版本可直接覆盖安装。

升级后，已有课表也默认采用 23 周有效期。若已超过有效期，可到“设置 → 课表与作息”延长周数或调整作废日期，保存后恢复显示；课程数据不会因作废而删除。

操作步骤见 [安装说明](https://github.com/jerryzrs-eng/kebiao/blob/v1.4.0/docs/安装说明.md)。
