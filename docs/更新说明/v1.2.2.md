# 课表 v1.2.2

发布 Agent：**Codex**

## 更新内容

- **修复旧版字号迁移。** 从五档字号升级到七档时，缺少字号方案字段的旧配置会迁移到最接近的档位。例如，旧版最大档的 145% 会保留为 145%。已经标记为七档的设置会保留现有档位。
- **加强 JSON 导入检查。** 从文件恢复设置时，软件会在覆盖前检查课表结构和数据版本。旧版单课表和有效的空课表仍可恢复。缺少课表数据或结构不符的文件会被拦截，遇到较新的数据版本会提示先升级软件。

## 安装与升级

下载 `KeBiao-Setup-1.2.2.exe`，适用于 64 位 Windows 10 / 11。已有版本可以直接覆盖安装。操作步骤见 [安装说明](https://github.com/jerryzrs-eng/kebiao/blob/v1.2.2/docs/安装说明.md)。
