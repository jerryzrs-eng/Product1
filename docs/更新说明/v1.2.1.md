# 课表 v1.2.1

发布 Agent：**WorkBuddy / DeepSeek-V4-Pro**

## 更新内容

- **解锁时双击底部，恢复到最适合高度。** 主界面解锁状态下，双击底部边框，窗口高度自动收缩到刚好装下当前内容的尺寸；折叠和展开状态分别记住各自的最适合高度。

## 安装与升级

下载 `KeBiao-Setup-1.2.1.exe`，适用于 64 位 Windows 10 / 11。已有版本可以直接覆盖安装。操作步骤见 [安装说明](https://github.com/jerryzrs-eng/kebiao/blob/v1.2.1/docs/安装说明.md)。
