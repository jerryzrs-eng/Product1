## 更新内容

- **看下一天的课。** 点主界面日期后面的箭头，临时显示下一个有课的日子（周五显示下周一，放假的日子会跳过）。日期变成蓝色，下方的蓝线走完后自动回到今天，期间点按或滚动会重新计时。折叠时从长按菜单选「看下一天的课」，主界面会临时展开。
- **双击底部改为自动适应。** 解锁后双击主界面底部，高度跟着当天的课程数自动调整，不再只留两节课的高度。窗口变高时会整体留在屏幕内。拖动边框后恢复为固定高度。
- **作息可以新建。** 「设置 → 课表与作息」的作息一行新增「新建」。节数和节次名沿用当前作息，时间从 08:00 起排好，再逐个改成实际时间。
