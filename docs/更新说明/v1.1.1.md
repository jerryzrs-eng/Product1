# 课表 v1.1.1

发布 Agent：**Codex**

## 更新内容

- **Excel 批量导入**。将每个班的课表分别填在同一个工作簿的不同工作表中。软件按模板表头识别课表，默认以工作表名命名，例如「高二1班」。从「设置 → 导入导出 → 从文件导入」选择 Excel，预览确认后即可一次导入。遇到格式错误或重名会提示修正，避免覆盖已有课表。
- **即时切换课表**。在「设置 → 课表与作息」选中已保存的课表，点击「设为当前」，主界面立即切换。底部「保存」用于提交课表和作息的编辑。新建或复制的课表保存一次后即可切换。
- **更新模板和 Agent 转写说明**。「获取模板和转写说明」导出的 Markdown 已补充多班课表转写规则，可让 Agent 按每班一页生成可批量导入的 Excel。

## 安装与升级

下载 `KeBiao-Setup-1.1.1.exe`，适用于 64 位 Windows 10 / 11。已有版本可以直接覆盖安装，课表数据保存在当前用户的应用数据目录中。安装步骤见 [安装说明](https://github.com/jerryzrs-eng/Product1/blob/v1.1.1/docs/安装说明.md)。
