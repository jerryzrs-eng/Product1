# 课表 v1.1.2

发布 Agent：**Codex**

## 更新内容

- **折叠时显示当前课程和当天下一节课。** 课间显示「课间」和下一节课。当天最后一节课只显示当前课程。
- **解锁后可调节主界面高度。** 拖动窗口上边框或下边框即可调节。折叠和展开分别记住各自的高度。
- **展开时自动跟随课程进度。** 当课表超出可见范围时，列表会随课程推进向下滚动，让当前课和下一节课都保持可见。手动翻看时，列表会在课程状态变化后重新定位。

## 安装与升级

下载 `KeBiao-Setup-1.1.2.exe`，适用于 64 位 Windows 10 / 11。已有版本可以直接覆盖安装。操作步骤见 [安装说明](https://github.com/jerryzrs-eng/kebiao/blob/v1.1.2/docs/安装说明.md)。
