# 课表 v1.2.0

发布 Agent：**WorkBuddy / DeepSeek-V4-Pro**

## 更新内容

- **字号改为等差 7 档，步长 15%。** 从原来的 5 档（特小/小/标准/大/特大）调整为 7 档（55% / 70% / 85% / 100% / 115% / 130% / 145%），标准为 100%。字号只缩放主界面课表，设置窗口的字号不受影响。
- **字号选择改为步进器。** 设置里的字号从分段单选改成 `− 100% +` 步进器，点击中间的百分比一键重置为标准（100%）。
- **老版本字号平滑迁移。** 已保存的字号会自动就近迁移到新档位，标准、特大保持不变，其余档位仅轻微调整，避免升级后字号突变。

## 安装与升级

下载 `KeBiao-Setup-1.2.0.exe`，适用于 64 位 Windows 10 / 11。已有版本可以直接覆盖安装。操作步骤见 [安装说明](https://github.com/jerryzrs-eng/kebiao/blob/v1.2.0/docs/安装说明.md)。
