# 课表 安装说明

## 装之前，在白板上确认三件事

1. **Windows 版本**：设置 → 系统 → 关于，需要 Windows 10 或 11（64 位）。Windows 7 装不上。
2. **有没有还原软件**：开始菜单里有没有“冰点还原”“还原精灵”“希沃管家-系统还原”这类软件，或者问电教老师。如果白板每次重启都会还原，装好的课表重启后就没了。需要请电教老师把课表加入“保留”名单，或者在解冻状态下安装。
3. **杀毒软件**：如果装了 360、火绒等，安装时可能被拦截，见下文。

## 安装

1. 用 U 盘把 `课表-安装-x.x.x.exe` 拷到白板上，双击运行。
2. 如果弹出蓝色的“Windows 已保护你的电脑”：点 **更多信息** → **仍要运行**。这是因为安装包没有购买数字签名，不是病毒。
3. 杀毒软件拦截时，选择 **允许** 或 **信任此程序**。
4. 安装过程不需要管理员密码。装好后课表会出现在桌面右上角。

## 第一次使用

1. 软件会自动打开“导入导出”页面。
2. 点 **获取模板和转写说明**，选一个文件夹（比如 U 盘），会得到两个文件：
   - `课表模板.xlsx`：照着填好就能导入。
   - `课表转写说明.md`：给 AI 助手看的说明。
3. 原课表格式不一样时：把 **原课表（照片/Word/Excel）+ 课表模板.xlsx + 课表转写说明.md** 一起发给 AI 助手，让它转写。
   - AI 给了 Excel 文件 → **从文件导入**。
   - AI 给了一段表格文字 → 复制，粘贴到 **粘贴导入** 框里 → **预览并导入**。
4. 在 **基本** 页填好班级和开学日期（用来算第几周、单双周）。

## 托盘图标

课表的图标在屏幕右下角（时间旁边）。Windows 11 会尝试自动设为常显。

如果只看到一个 `^` 箭头：点开它，把课表图标**拖到**任务栏上，以后就一直显示。

- **单击**图标：课表临时浮到最上面 10 秒（被 PPT 挡住时用）。
- **右键**或**长按**图标：今天按周几上课、放假、拖动调课、设置、退出。

在课表上**长按**（或右键）也能打开同样的菜单。

## 升级

拿新版本安装包直接运行，覆盖安装即可。课表数据保存在 `%AppData%\KeBiao`，升级、卸载都不会删除。

## 数据和备份

- 每次修改前自动保存一份历史版本，最多 20 份，在 **设置 → 历史版本** 里一键恢复。
- **设置 → 导入导出 → 导出到文件** 可以把全部设置拷到另一块白板上。
